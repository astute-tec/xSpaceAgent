# 声纹注册操作指南

> 设备已就绪（LED 亮、屏幕显示），三人各 3 分钟即可完成。

## 你要做的

三个人**依次**到设备前面来，我遥控设备录音，你告诉他们该说什么。

## 我需要你告诉我的

**三个人的名字和角色**，比如：
- 文剑（售前/技术）
- 进坤（销售/商务）
- （第三个人名+角色）

你直接回复告诉我，我立刻开始逐一录入。

## 每个人的操作流程（约 3 分钟）

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | 我通过串口触发录音 | 设备屏幕出现录音状态 |
| 2 | 你让这个人**跟着念**下面的引导文字 | 我会用 TTS 外放引导（或你看下面的文字提示他） |
| 3 | 念完了我停止录音、提取声纹 | 自动完成 |

**引导文字**（我在屏幕上显示、或你口头引导）：

```
第一遍（自我介绍，说 2 遍）：
  "我是XXX，负责XXX"
  （例：我是文剑，负责售前和技术支持）

第二遍（自然语句，念 2 遍）：
  "今天我们在讨论项目进展和后续的安排，
   方案是优先走 UDP，如果网关不支持就自动回退到 TCP，
   下午还要确认兼容性，把客户端的版本再测一遍。"

第三遍（报名确认）：
  "我是XXX"
```

念的时候：
- 离设备 **0.5~1 米**
- 正常音量说话（不要刻意大声或小声）
- 语速正常，不要念太快

## 你只需要做的

**回复我三个人的名字，我立刻开始第一个人的录入流程。** 每个人录完我告诉你"换下一个"。
