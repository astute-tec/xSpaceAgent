## 踩过的坑（都写进文档了）

1. **SSID 区分大小写**：`xspace` ≠ `xSpace`，报 201（找不到 AP）。
2. **页面手动输入框覆盖点选**：残留一个 `d` 导致设备一直连 `"d"`。已改为"点使用按钮才生效"，点选网络自动清空输入框。
3. **圆屏排版**：按矩形排版时配对码被圆形边缘切掉。已按内接区域重排。
4. **配对码白底白字**：七段数码管默认白色，和背景同色，肉眼不可见。已改黑字。
5. **RGB565 字节序**：`0x07E0`（绿）在该面板上显示成暗红。结果界面改为**纯黑白**，不受字节序影响。
6. **错误码被覆盖**：自己调 `esp_wifi_disconnect()` 产生的 reason=36 覆盖了真实的 201。已过滤。

## 关键结论

- **配网方案**：手机配网页适合日常，但**串口直连才是最可靠的**（现场排障/产线），两条路都保留。
- **语音链路可行**：板子自带 AEC 参考信号，双麦 + 回声消除的硬件基础齐了。

**麦克风排查到哪一步**：

- I2C 扫描：`0x18`(ES8311) `0x34`(AXP2101) `0x40`(ES7210) `0x5A`(触摸) 都在
- 电源寄存器：`AXP[0x90]=0x01`（ALDO1 已开）、`AXP[0x92]=0x1C`（3.3V）、`AXP[0x82]=0x12`（DC1 3.3V）→ **供电正常**
- ES7210 寄存器：chip id `0x41`、增益寄存器 `0x41–0x46=0x70` → **芯片已配置**
- 但 I2S 读回来的 PCM 全是 0 → 怀疑 **I2S 主从/格式不匹配**（ES7210 可能工作在 master，或 TDM 帧错位）

**根因**：只建了 I2S RX 通道，缺 TX 通道和 ES8311 初始化 → 时钟/数据通路没起来。改成与官方 BoxAudioCodec 一样的**双工初始化**（TX 标准 + RX TDM 4 槽 + 24kHz + ES8311 与 ES7210 都打开 + 输入增益 30dB）后，麦克风立刻有信号。

**端到端验证**：板子录 12 秒（Mac 外放测试对话）→ 上传 1.15MB → hub 转写 → 过滤 → 日报，全自动完成。

## 离线队列（20:05–20:50 完成并验证）

**回答"设备不在线会怎样"**：以前会丢，现在不会了——

```
录音中：每 20 秒把一段转单声道写入 Flash 队列（FATFS，27MB ≈ 9 分钟）
   ↓ 上传失败/断网 → 段留在 Flash，绝不丢
联网后：flush 任务每 5 秒扫队列 → 逐段自动补传 → 成功即删
   每段独立：单段失败只影响那一段
```

**实现细节**：
- 存储从 SPIFFS 换成 **FATFS**（SPIFFS 格式化 28MB 要 10+ 分钟，FATFS 秒级）
- 录音**双缓冲**：A 段写盘时 B 段继续采集，写盘不阻塞录音
- 分段 20 秒单声道（1.4MB/段）→ 上传快、失败损失小
- 上传地址 NVS 持久化（重启不丢）
- 修了启动崩溃：flush 任务发网络请求必须在网络栈初始化之后
