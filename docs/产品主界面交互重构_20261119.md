# 圆形表盘主界面与交互重构 · 2026-11-19

## 目标

将 466×466 AMOLED 主界面改为常驻黑底圆形表盘：待机显示时间和录音图标；录音时在 6 点位上方显示随真实麦克风能量平滑变化的波形；问答监听时在同一位置显示动态麦克风；底键长按停止录音时显示 3 秒进度。

## 交互验收

1. 上键第一次从任何设置页返回表盘；回到表盘后下一次单击开始录音。
2. 上键双击进入问答监听，动态显示麦克风；再按上键提交当前问题，等待云端返回并语音播报。
3. 底键短按熄屏/亮屏，不改变录音；录音中长按 3 秒，表盘原位显示停止进度并封存录音。
4. 顶部下滑打开 WiFi 与声纹设置；声纹页加号逐个录入空槽，成功后显示成员头像。
5. 表盘更新时间不阻塞 AFE、录音、Flash 保存与网络任务。

## 设计参考

联网检索了极简黑色圆形 AMOLED / 智能手表表盘设计，采用高对比时间、低亮度刻度与单一强调色的方向。绘制采用固件原生矢量原语，不依赖大位图或额外下载资源，降低 Flash 占用并保持离线可用。

## 实现结果

- 新主界面是黑底圆形刻度、醒目数字时钟与日期；设备用 NVS 保存最近一次 SNTP 时间，断网重启时恢复基准时间。
- 待机时 6 点上方显示线框麦克风；录音时在同一位置绘制 AFE 麦克风 RMS 历史经 Catmull-Rom 平滑后的曲线。
- 问答监听复用该位置的青色动态麦克风；提交后显示思考/回答状态，播报音量设为 codec 0–100 刻度的 100。
- 录音中底键按下时显示 3 秒进度，完成后封存并停止；短按仍切换屏幕，不影响录音。
- `wifi_provision.bin` 大小 `1,937,264` 字节（`0x1d8f70`），SHA-256 `c74e19ef9e38b7a496325606c7a974224d528a2ce500abe3461580c808306c79`，应用分区剩余约 54%。已写入应用分区并通过校验；NVS、模型与录音存储分区未写入。
- 烧录后启动日志显示 Flash 队列有 34 段待补传，队列分区未改写。串口打开曾触发芯片复位，复位前尚未封存到 Flash 的 RAM 尾段可能未能保存；之后的新固件启动正常。
- 当前仅确认启动和 WiFi 连接，表盘交互、持续录音及问答完整流程仍需现场实测。
