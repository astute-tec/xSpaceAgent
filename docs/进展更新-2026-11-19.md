# 进展更新 · 2026-11-19

## 外出实测问题修复（13:50）

**现象**：带出门后屏幕黑、单按上面键没反应，双击才偶尔闪出麦克风画面。

**根因**（三个叠加）：
1. **AUTO 开关重启后丢了**：`s_auto` 没有从 NVS 恢复，重启后 `s_auto=false`，
   而"静音 10 秒熄屏"的逻辑写在 `if (s_auto)` 里 → 逻辑完全不跑 → 屏幕状态错乱
2. **单击开始录音后被判"静音"熄屏**：录音开始时 `last_speech=0`，
   `now - last_speech > 10000` 立刻成立 → 刚开始录就把屏幕熄了 → 用户以为没反应
3. **熄屏逻辑绑死在 AUTO 模式**：外出单次录音也需要"有声亮屏/静音熄屏"

**修复**：
- `s_auto` 默认 true + 从 NVS 恢复用户上次的选择
- 熄屏/亮屏逻辑**不再依赖 AUTO 开关**：录音中一律"有声亮屏、静音 10 秒熄屏"
- 单击开始录音 = 屏幕亮起 + 声波界面（红点 + 录音中 + 计时）

**上面键新行为（已实测）**：
| 场景 | 按上面键 |
|---|---|
| 任何设置页 | 回主界面（不再进录音） |
| 待机 | 开始录音 |
| 录音中 | 无反应（防误触） |
| 连按两下 | 语音问答（等同"你好小智"） |

**问答链路修复**：
- 问答与队列上传并发时 TLS 内存不足 → 加全局 HTTP 串行锁
- 问答 body 分块写（之前一次写 192KB 失败）
- 超时放宽到 60 秒（服务端 ASR+Agent+TTS 需要 10-30 秒）
- **实测**：`ask http=200`，`answer pcm 716024 bytes` 回到设备播放

**显示修复**：
- 中文字库自动扫描源码补全（"思考中""回答中"之前缺字，只显示一个"中"）
- RGB565 字节序修复（fill_rect 统一交换字节）：红点真红、青点真青（之前黄点/暗红）
