## 修改与验收目标

- 声纹以同一个后台任务负责落盘后的上传与回执。待上传占住对应名额，只有得到服务端成功回执并保存设备状态才显示头像。恢复已经在服务端入库而设备漏记的名额时只同步元数据。
- 问答区分听、发送、等待、播放与失败；问答优先于普通录音补传，退出后恢复原有录音；保留 HTTP 回复和播放字节数供复核。
- 显式加载并记录唤醒词模型，自动问答与上键问答统一使用监听显示。验证时分别检查唤醒词命中、问题音频、转写、唐僧回答和播报。
- 波形卡顿单独排查：旧版每帧刷整屏并忽略 SPI 提交/等待失败。改为平时只传输表盘底部动态区域，SPI 错误退出当前帧并保留 DMA 缓冲所有权；从后台收到的音频不能单独证明现场录音未中断。
