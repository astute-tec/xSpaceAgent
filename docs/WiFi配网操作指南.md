# WiFi 配网操作指南（v1.8）

## 方式一：蓝牙配网（推荐，不用扫码）

1. 手机上装 **「ESP Blufi」** App
   - iOS：App Store 搜 "ESP Blufi"（Espressif 官方）
   - Android：应用市场搜 "ESP Blufi"，或从 espressif.com 下载 APK
2. 设备屏幕**顶部下滑** → 点 **WiFi 圆钮**（左边那个）→ 屏幕显示二维码
   - 此时设备的蓝牙和热点同时开启
3. 打开 ESP Blufi App → 点 **「扫描」/「I am ready」** → 列表中选 **`Xiaozhi-54D9`** → 连接
4. 在 App 里点 **「配置 WiFi」** → 输入办公室 WiFi 名称和密码 → 确认
5. 设备自动连接，连接成功后**蓝牙自动关闭**（省电，把内存还给录音）

## 方式二：手机扫码（不用装 App）

1. 设备屏幕**顶部下滑** → 点 **WiFi 圆钮** → 屏幕显示二维码
2. **用手机相机直接扫屏幕上的二维码**（不是微信扫）
   - 二维码内容是 `WIFI:T:nopass;S:Xiaozhi-54D9;;`
   - iPhone / 安卓相机扫到后会自动提示"加入网络 Xiaozhi-54D9"→ 点加入
3. 加入后手机会自动弹出配网页面（或浏览器打开 `http://192.168.4.1/`）
4. 页面上选择办公室 WiFi → 输入密码 → 输入屏幕上的 6 位配对码 → 提交
5. 设备自动连接

## 方式三：串口配网（调试用）

```
WIFI <SSID> <密码>
```
例如：`WIFI DYZN88 daye8888`

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| WiFi 报 201 | 找不到该热点 | 热点关了/走远/名字变了，重新配网 |
| WiFi 报 202/15 | 密码错 | 重新输入密码 |
| 连上后无法上传 | 域名 DNS 解析失败 | 设备会 5 分钟自动重试；数据存在本地队列不丢 |
| 蓝牙搜不到 | 没进配网模式 | 先下滑 → 点 WiFi 圆钮（或串口发 `PROV`） |

## 配网状态查询

串口命令：
- `STATUS` — 显示 state（0=未连接 / 2=已连接）、IP、SSID
- `HEAP` — 查看内部 RAM 余量
- `SCAN` — 扫描周围 WiFi
